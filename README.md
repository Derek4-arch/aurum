# Aurum

Playable desk synth. Sound starts after you tap Arm or a key.

Home row plays one octave (`A S D F G H J K`, sharps on `W E T Y U`). Brackets shift octave. Space holds the pedal.

```bash
npm install
npm run build
npm start
```

`PORT` sets the listen port. `VITE_AUTH_ENABLED=false` keeps the instrument open without sign-in.
